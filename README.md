# Fact-check audit

A RAG-based claim verification system with a built-in audit layer that tests the
fact-checker for subgroup bias, robustness, calibration, citation faithfulness and drift.

Status: Phase 1, learning foundations.

## Layout
- `src/` project code
- `notebooks/` experiments
- `data/` datasets (not committed)
- `reports/` write-ups and audit reports
- `exercises/` learning exercises
- `tests/` automated tests
